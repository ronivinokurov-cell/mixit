# MIXIT 🌈

כל העולם שלך באפליקציה אחת: ארגון אישי, מחולל פעילויות וסטודיו עיצוב דיגיטלי.

- **בית** – סיכום יומי, קיצורי דרך, רעיון ואתגר היום, התקדמות.
- **ארגון** – יומן, משימות, שיעורי בית ומבחנים, מטרות, קניות ומשאלות, תקציב, מערכת שעות, טיימרים, ספירה לאחור, סיכום שבועי והערות.
- **מה עושים עכשיו?** – מחולל פעילויות לפי זמן, תקציב, משתתפים וסוג, מועדפים, פעילויות אישיות וחידות.
- **יצירה ועיצוב** – סטודיו קנבס: כרזות, הזמנות, כרטיסי ברכה, רקעים, יומן, קולאז׳, ציור, מדבקות, חולצות, כריכות, לוחות השראה ופלטות צבעים. שמירה, עריכה, הורדה ושיתוף.
- **הפרופיל שלי** – ערכות צבעים, רקעים, אייקונים, מסך בית מותאם, תיקיות, הישגים, גיבוי ושחזור.

כל הנתונים נשמרים מקומית בדפדפן (localStorage). אין צורך בהתחברות.

## פיתוח
```
node build.js   # בונה index.html מ-src/
node t2.js      # בדיקות smoke עם jsdom
```

נבנה עם HTML/CSS/JS ללא תלויות ריצה.
